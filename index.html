STEP 1 역할 (Role)
"너는 자동차 부품 제조사 구매 담당자야."
STEP 2 배경 (Context)
"원자재 공급사가 단가 8% 인상을 일방 통보해왔어."
STEP 3 지시 (Task)
"인상 근거 자료를 요구하고 분기별 단계적 인상을 제안하는 회신 메일을 써줘."
STEP 4 형식 (Format)
"정중하면서도 단호한 어조로, 3개 문단 이내의 비즈니스 양식으로."

(실습 1) 거래명세서 파일 내용을 표로 만들기

🖼️ sample-01-resin.png
⬇️ 다운로드

스마트폰으로 촬영한 서류 사진을 Claude 대화창에 첨부하고 아래 순서대로 프롬프트를 전송하세요.

STEP 1 : 사진 속 품목 추출
첨부한 거래명세서의 품목 표를 읽어서 표로 만들어줘. 열: 귀사 품번, 공급사 코드, 품명, 규격, 단위, 수량 단가와 금액은 빼줘. 표 위에 명세서 번호, 거래 일자, 공급자 상호를 따로 적어줘. 읽기 어려운 칸은 추측하지 말고 '확인 필요'라고 적어줘.
STEP 2 : 엑셀 복사용 탭 구분 변환
이 표를 엑셀에 바로 붙여넣을 수 있게 탭(Tab)으로 구분한 텍스트 형식으로 다시 보여줘.
STEP 3 : 원문 대조 검증 (합계 수량 비교) 환각 방지 검산
표의 행 수와 수량 합계를 알려줘. 그리고 서류 아래쪽 합계 칸에 적힌 수량과 같은지 비교해줘.

(실습 2) 업무별 프롬프트 모음 (11종)

공통·구매·자재·품질·영업·관리

부서 탭을 선택하고 원하는 프롬프트를 복사한 뒤, 내 상황에 맞게 괄호 안의 내용을 수정하여 실행해 보세요.

💡 결과 다듬기 팁 (클릭 시 복사) 원하는 칩을 눌러 대화창에 바로 붙여넣기
⚠️

생성형 AI 사용 시 필수 유의사항

AI의 결과물은 반드시 실무자의 교차 검증을 거쳐야 하며, 기업 내부 기밀 정보 보호 원칙을 준수해야 합니다.

PART 02

AI를 활용하여 엑셀 작업해보기

정돈되지 않은 부품 목록을 AI로 자동 정제하고 필수 수식과
조건부 서식을 완성합니다.

실습 도구: Claude 웹 서비스 (https://claude.ai) ↗

기존 부품목록.xlsx의 문제점

  • • 품번 표기 제각각: sk-ad-001, SK AD 003, SKPD001 혼재
  • • 불필요한 중복 행: 표기만 달라 중복 등록된 부품 다수
  • • 단위 혼용: ea, Ea, 개, 박스, Box 혼재
  • • 애매한 안전재고: 150개, 약 80, 1백20 텍스트 혼입

AI 정제 후 표준화 기준

  • • 표준 품번: 대문자 SK-분류-세자리번호 통일
  • • 중복 제거: 고유 품번 기준 1건만 단일화 유지
  • • 표준 단위: EA, BOX, BAG 3대 단위 규격화
  • • '확인 필요' 열 신설: 모호한 데이터는 추측하지 않고 검수 표시

엑셀 데이터 자동 정제 프롬프트

📊 부품목록_실습.xlsx ⬇️ 다운로드

부품목록_실습.xlsx 파일을 다운로드하여 Claude 대화창에 올린 후 아래 프롬프트를 전송하세요.

PROMPT : 데이터 표준화 & 정제 규칙
첨부한 엑셀의 '부품목록' 시트는 여러 사람이 입력해서 표기가 제각각이야. 아래 규칙으로 정리해서 엑셀 파일로 돌려줘. 1. 품번은 SK-분류-세자리번호 형식 (예: SK-AD-005). 대문자, 공백 없이. 2. 품번이 같은 행은 하나만 남겨. 3. 빈 행과 메모 행은 지워. 4. 단위는 EA, BOX, BAG 중 하나로. 5. 거래처는 (주), ㈜, 주식회사, 띄어쓰기를 빼고 회사 이름만. 6. 안전재고는 숫자만. 뜻이 애매한 값은 지우지 말고 '확인 필요' 열을 만들어 이유를 적어. 7. 등록일은 YYYY-MM-DD. 연도가 없으면 2026년. 마지막에 무엇을 몇 건 고쳤는지 표로 알려줘.
PROMPT : 열 이동 및 단가표 매칭 수식
현재 I열의 내용을 J열로 이동 후 다음 작업을 수행해줘. 엑셀에서 쓸 수 있는 함수로 알려줘. '부품목록' 시트 A열 품번으로 '단가표' 시트(A열 품번, B열 단가)에서 단가를 찾아 I열에 넣는 수식. 단가가 없으면 '단가 없음'이라고 나오도록

PROMPT : 단일 HTML 입출고 웹페이지 시스템 전체 생성
자동차 플라스틱 부품 제조 중소기업에서 쓸 "부품 입출고관리" 웹페이지를 HTML 파일 하나로 만들어줘. 화면은 한국어, 큰 글씨와 높은 대비로 해줘. 프로젝터로도 읽히고 휴대폰 화면(400px)에서도 쓸 수 있어야 해. 데이터는 브라우저 저장소(localStorage)에 저장하고, 인터넷 없이 동작해야 해. [데이터]- 부품: 품번, 품명, 규격, 단위, 안전재고, 보관 위치, 사용 여부- 입출고 기록: ID, 구분(입고/출고/취소), 품번, 수량, 거래처 또는 사용처, 작업자, 메모, 원래 기록 ID(취소일 때), 일시- 현재고는 따로 저장하지 말고 기록을 합산해서 계산해. 기록은 수정하거나 지우지 않고 추가만 해. [화면] 위쪽 메뉴로 이동 1. 대시보드: 숫자 카드 4개(전체 품목, 안전재고 미달, 오늘 입고 건수, 오늘 출고 건수), 안전재고 미달 목록, 최근 입출고 10건 2. 입고: 스캔 입력칸에 항상 커서가 있게 해줘. USB 바코드 스캐너는 품번을 입력하고 Enter를 보내는데, Enter는 부품을 고르기만 하고 저장은 [입력] 단추로만 해. 부품을 고르면 품명과 현재고를 보여주고, 수량(기본 1)·거래처·작업자·메모를 받아. 같은 품번을 다시 스캔하면 수량을 1 올려줘. 없는 품번이면 경고하고 "새 부품으로 등록" 단추를 보여줘. 저장되면 화면 효과와 소리로 알려줘. 3. 출고: 입고와 같은 방식이고, 거래처 대신 사용처(생산 라인 또는 고객사)를 받아. 현재고보다 많이 출고하면 막고, 출고한 뒤 안전재고 아래로 떨어지면 경고해줘. 4. 재고 현황: 품목별 현재고 표. 안전재고 미달은 빨간색으로 맨 위에 보여줘. 품번·품명·위치로 검색해. 5. 이력: 기간·품목·구분으로 조회해. 잘못된 기록은 [취소]를 누르면 "취소" 기록을 새로 남겨 바로잡아. 6. 부품 관리: 등록·수정. 품번이 중복되면 막아줘. 기록이 있는 부품은 삭제 대신 "사용 중지"로 바꿔. 7. 설정: 샘플 데이터 불러오기, 전체 초기화(확인 단계 거치기) [품번 체계] SK-분류-세자리번호 분류: AD 에어벤트 덕트, PD 페달 부품, CS 케이스류, RM 원자재(수지), SB 부자재 [샘플 데이터] 가상 데이터로 부품 25개(분류별 4~6개, 예: SK-AD-001 에어벤트 덕트 센터, SK-RM-001 PP 수지 25kg/포)와 최근 2주 입출고 기록 100건쯤 만들어줘. 안전재고 미달 품목이 3~4개 보이게 해줘. 거래처 예시는 대한수지, 한빛폴리머, 동방부품, 세진포장이고 사용처 예시는 사출 1라인, 사출 2라인, 조립라인, 고객사 납품이야. 화면에 출력하는 사용자 입력은 모두 이스케이프해줘. 수량은 1 이상의 정수만 받아.
